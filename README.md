# 🐢 Turtle Crossing Game

A simple arcade-style road crossing game built using **Python and the Turtle graphics library**.

The player controls a turtle and must cross a busy road while avoiding randomly moving cars. Each successful crossing increases the level and makes the cars faster, increasing the difficulty of the game.

## 🎮 Features

* 🐢 Four-direction turtle movement
* 🚗 Randomly generated cars
* 🎨 Multiple car colors
* 🚦 Car spawning with reduced overlap
* 💥 Collision detection
* 🏁 Finish-line detection
* 📈 Level progression
* ⚡ Increasing car speed with each level
* 🏆 Level scoreboard
* 💀 Game Over system

---

## 🕹️ Controls

| **Key**        | **Action** |
| -------------- | ---------- |
| ⬆️ Up Arrow    | Move Up    |
| ⬇️ Down Arrow  | Move Down  |
| ⬅️ Left Arrow  | Move Left  |
| ➡️ Right Arrow | Move Right |

---

## 🛠️ Technologies Used

* **Python 3**
* **Turtle Graphics**
* **Random Module**
* **Time Module**

No external Python libraries are required.
